# راهنمای پنل وردپرس خشت

## نصب (یک‌بار)
1. وردپرس را روی هاست/سرور نصب کنید (یا محلی: `docker compose up -d` از ریشه‌ی پروژه).
2. پوشه‌ی `wp-content/plugins/khesht-core` و `wp-content/themes/khesht-headless` را کپی کنید.
3. در پنل: **افزونه‌ها ← Khesht Core ← فعال‌سازی** و **نمایش ← پوسته‌ی Khesht Headless ← فعال‌سازی**.
   - هنگام فعال‌سازی: جدول دیتابیس درخواست‌ها ساخته می‌شود، نوع ملک/نوع معامله/دسته‌های مجله و ۵ خدمت پیش‌فرض ثبت می‌شوند.
4. **تنظیمات ← پیوندهای یکتا** را یک‌بار ذخیره کنید.
5. **تنظیمات ← Khesht (خشت)**: تلفن، نشانی، شبکه‌ها، شماره‌ی دریافت پیامک و عکس هیروها.
6. در `wp-config.php` یا متغیر محیطی: `KHESHT_FRONTEND_ORIGIN`، کلیدهای پیامک و قیمت (فایل `.env.example` افزونه).

## هر بخش سایت از کجا مدیریت می‌شود
| بخش سایت | منوی پنل |
|---|---|
| املاک (کارت و صفحه‌ی اختصاصی هر ملک) | املاک ← افزودن ملک: عنوان و توضیحات، **تصویر شاخص** (عکس کارت)، کادر «مشخصات ملک» (متراژ، قیمت حدودی، کد فایل، **لینک بازدید ویدئویی**، تعداد خواب، سند، امکانات، گالری تصاویر و ...)، و طبقه‌بندی‌های «نوع ملک»، «نوع معامله»، «موقعیت» |
| مقاله‌های مجله (هر تعداد) | نوشته‌ها ← افزودن نوشته: **دسته** (آموزش املاک / ساخت‌وساز / تحلیل بازار / پادکست و رسانه)، تصویر شاخص، چکیده. برای پادکست، لینک فایل صوتی/ویدئو را در کادر «پادکست / رسانه» بگذارید. سایت خودش صفحه‌بندی و فیلتر دسته را انجام می‌دهد |
| پروژه‌ها و نمونه‌کارها (کارت و صفحه‌ی اختصاصی) | پروژه‌ها و نمونه‌کارها ← دسته (ساخت‌وساز یا شهرک‌سازی)، وضعیت (اجراشده/در حال اجرا)، موقعیت، متراژ، سال، مدت اجرا، تعداد واحد، ویژگی‌ها، گالری |
| فایل‌های اقتصادی | همان «املاک»؛ در «نوع ملک» گزینه‌ی **فایل‌های اقتصادی** را انتخاب کنید. این فایل‌ها در صفحه‌ی `/amlak/economic/` و با فیلتر املاک دیده می‌شوند |
| شماره‌ی تماس هر دسته‌ی ملک | تنظیمات ← Khesht ← «شماره‌ی تماس هر دسته‌ی ملک». در خود فایل هم می‌شود شماره‌ی اختصاصی داد (اولویت با آن است) |
| تجربه مشتریان: نظرها و مشتریان (CRM) | منوی **تجربه مشتریان**: «نظرات» (تأیید/رد/حذف/پاسخ) و «مشتریان (CRM)» (فهرست، یادداشت، ارسال رمز جدید، مسدودسازی، CSV) |
| صفحه‌ی مهندس نوروزی (عکس، نام، متن معرفی) | تنظیمات ← Khesht ← «مهندس نوروزی» |
| وبلاگ مهندس نوروزی | نوشته‌ها ← دسته‌ی «وبلاگ مهندس نوروزی» (در مجله‌ی عمومی نمایش داده نمی‌شود) |
| اعضای مجموعه (هر تعداد کارت) | تیم ← افزودن عضو (نام، سمت، توضیح، تصویر شاخص). ترتیب با «ترتیب» در کادر ویژگی‌های صفحه |
| گالری صفحه‌ی «درباره ما» | **گالری** (منوی کنار پنل): انتخاب چند تصویر، کشیدن برای مرتب‌سازی، حذف. زیرنویس از «توضیح/عنوان» تصویر در کتابخانه‌ی رسانه |
| خدمات صفحه‌ی اول | خدمات (آیکون از لیست انتخاب می‌شود) |
| برآورد قیمت مناطق (صفحه‌ی بازار) | قیمت مناطق |
| برندهای همکار | همکاران |
| عکس هیرو، تلفن، نشانی، شبکه‌ها، کپی‌رایت | تنظیمات ← Khesht (خشت) |
| درخواست‌های مشاوره و همکاری | **درخواست‌ها** (منوی کنار پنل، با نشان تعداد جدید) |

## درخواست‌ها (دیتابیس + پیامک)
- هر فرم مشاوره/همکاری در جدول `wp_khesht_requests` ذخیره می‌شود، سپس پیامک به شماره‌ی تنظیم‌شده می‌رود.
- در **درخواست‌ها** می‌توانید: وضعیت را عوض کنید (جدید / در حال پیگیری / انجام شد / اسپم)، یادداشت داخلی بنویسید، پیامک ناموفق را دوباره بفرستید، حذف کنید و **خروجی CSV** (قابل‌باز در اکسل) بگیرید.
- اگر پیامک ارسال نشد، درخواست از دست نمی‌رود؛ وضعیت پیامک «ناموفق» می‌شود.

## اتصال سایت به پنل
فرانت‌اند (Vite) در `.env`: `VITE_API_BASE=https://cms.khesht123.com` (آدرس وردپرس). هر بار محتوا عوض می‌شود، وب‌هوک (`KHESHT_FRONTEND_REBUILD_URL`) می‌تواند build سایت را دوباره اجرا کند.

## API ها (فقط‌خواندنی، بدون لاگین)
`/wp-json/khesht/v1/` ← `site`, `properties`, `properties/{slug}`, `taxonomies`, `team`, `services`, `partners`, `projects?group=&status=&limit=`, `magazine`, `magazine/{slug}`, `area-prices`, `market-quotes`, `search?q=`  
ارسال فرم‌ها (POST): `consultation`, `collaboration`.

## آدرس صفحه‌های جزئیات
صفحه‌ی هر ملک/پروژه/مقاله با شناسه باز می‌شود، مثلاً `/amlak/property/?id=123`، `/project/?id=45`، `/mag/article/?id=67`. نیازی به تنظیم بازنویسی آدرس (rewrite) روی هاست نیست و ملک/پروژه/مقاله‌ی جدید بدون build دوباره بلافاصله دیده می‌شود.

## ثبت‌نام مشتریان و پیامک رمز
- مشتری نام و شماره‌ی موبایل می‌دهد؛ رمز ۶ حرفی را سیستم می‌سازد و **پیامک** می‌کند (مشتری رمز نمی‌سازد).
- تا زمانی که پنل پیامک وصل نشده (`KHESHT_SMS_ADAPTER=mock`)، پیامی نمی‌رود؛ آخرین پیام‌ها (با رمزها) بالای صفحه‌ی **مشتریان (CRM)** نشان داده می‌شوند تا بتوانید تست کنید.
- بعد از اتصال پنل (مثلاً `kavenegar`)، همان کد خودکار پیامک را می‌فرستد.
- ورود: شماره + رمز. ۵ رمز اشتباه پشت‌سرهم، ۱۵ دقیقه قفل می‌کند. «فراموشی رمز» رمز جدید پیامک می‌کند.
- نظرها پیش‌فرض بعد از تأیید شما منتشر می‌شوند (می‌توانید در تنظیمات خودکار کنید).
